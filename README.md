The `noneos` release also has the versioned file (`NoneOS-R11.xx.apbx`). It is identical to `NoneOS.apbx`.

## Install NoneOS
1. Download `NoneOS.apbx`.
2. Open [AME Wizard](https://ameliorated.io) and drag the `.apbx` file into it.
3. Pick your options and start. Keep an internet connection during the run: the playbook downloads the Toolbox, the apps and the optional FIVEMOS pack from this repo.

Each release lists the file size and MD5 so you can check your download.
